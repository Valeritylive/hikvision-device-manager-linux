# Hikvision Device Manager для Linux

Бесплатная графическая программа с открытым исходным кодом для обнаружения и базового обслуживания устройств Hikvision в локальной сети. Интерфейс построен на GTK 4; поиск совместимых устройств выполняется по локальному SADP-протоколу через UDP-порт 37020.

Поддерживаются Linux amd64 и два готовых формата установки: AppImage и Debian/Ubuntu `.deb`. HCNetSDK не входит в сборки и устанавливается отдельно, если нужны операции, которые зависят от SDK.

## AppImage

Скачайте `HikvisionDeviceManager-x86_64.AppImage` со страницы [последнего релиза](https://github.com/Valeritylive/hikvision-device-manager-linux/releases/latest). Откройте терминал в каталоге загрузки и запустите:

```bash
chmod +x HikvisionDeviceManager-x86_64.AppImage
./HikvisionDeviceManager-x86_64.AppImage
```

Собрать AppImage вручную на Linux x86_64 можно командой `bash build-appimage.sh`; потребуются `wget`, `file` и доступ к Интернету для загрузки инструментов сборки и библиотек. Исходный код приложения и GTK/GStreamer/Python-пакеты включаются в образ. HCNetSDK не включён; функции через SDK требуют отдельной установки официальной библиотеки и указания `HIKVISION_HCNETSDK_LIBRARY`.

## Пакет Debian/Ubuntu (.deb)

Скачайте `hikvision-device-manager_1.0.0-1_amd64.deb` со страницы [последнего релиза](https://github.com/Valeritylive/hikvision-device-manager-linux/releases/latest), затем установите его командой:

```bash
sudo apt install ./hikvision-device-manager_1.0.0-1_amd64.deb
```

Пакет предназначен для Debian/Ubuntu amd64 и содержит Python, GTK 4 и GStreamer, поэтому отдельно устанавливать зависимости Python не нужно. После установки приложение появится в меню программ; его также можно запустить командой `hikvision-device-manager`. Релиз включает оба готовых пакета. Непомеченные релизные сборки также доступны в артефактах GitHub Actions.

Для сборки `.deb` вручную сначала выполните `bash build-appimage.sh`, затем `bash build-deb.sh`. Для AppImage достаточно `bash build-appimage.sh`; для загрузки инструментов и библиотек требуется доступ к Интернету.

## Запуск из исходников на Debian/Ubuntu

Установите системные зависимости:

```bash
sudo apt install python3 python3-gi gir1.2-gtk-4.0 python3-requests python3-cryptography python3-gst-1.0 gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-libav
```

Затем запустите приложение из каталога проекта:

```bash
python3 app.py
```

Список обновляется автоматически каждые 15 секунд. Можно фильтровать и сортировать устройства, экспортировать список в CSV со всеми обнаруженными XML-полями, выбрать несколько устройств для пакетной активации или раздать им диапазон IPv4 адресов. Карточка устройства показывает IPv4/IPv6 адреса и сетевые порты, если они есть в ответе обнаружения. Для одного устройства доступны активация, настройка email, настройка контрольных вопросов, экспорт GUID-файла и изменение IPv4/IPv6. Перед изменением IP приложение показывает текущие настройки интерфейса, включая маску, шлюз и DNS; можно задать статический IPv4, включить DHCP и настроить статический IPv6. Пакетная смена адресов работает с IPv4. Для поиска приложению нужен доступ к UDP-порту 37020; для настройки — доступ к HTTP-порту устройства (обычно 80).

Активация сначала использует локальный ISAPI endpoint, а при ошибке пробует HCNetSDK, если вы установили SDK отдельно и указали путь через `HIKVISION_HCNETSDK_LIBRARY`. Кнопка «Камеры через NVR» подключается к регистратору по HCNetSDK и показывает камеры из его SADP-списка; для них доступны смена IPv4/DHCP, шлюза, DNS и SDK-порта с проверкой текущим паролем камеры. Порт NVR по умолчанию — 8000, имя пользователя — `admin`. Кнопка «Открыть видео в реальном времени…» запускает отдельное окно RTSP-просмотра: введите учётные данные камеры и выберите основной или дополнительный поток. По умолчанию используются RTSP порт 554 и Hikvision URL `/Streaming/Channels/101` или `/Streaming/Channels/102`; RTSP порт берётся из SADP-ответа, если устройство его сообщает. Для сетевого видео требуется доступ к RTSP-порту камеры. В настройках отдельного устройства можно прочитать и изменить HTTP/HTTPS/RTSP/SDK-порты, которые оно объявляет через ISAPI, а также запросить отвязку Hik-Connect, если устройство объявляет эту возможность. Отвязка требует пароль администратора и подтверждение. Для настройки резервной почты и контрольных вопросов устройство должно быть активировано; потребуется его пароль администратора. Возможность настройки зависит от модели и прошивки. Hikvision может потребовать подтверждение email через QR-код; такой адрес не считается проверенным до завершения этого шага на стороне Hikvision. ISAPI передаёт номера контрольных вопросов, но не их формулировки, поэтому сверяйте номер с интерфейсом устройства.

## Текущие ограничения

- Поиск рассчитан на локальный сегмент сети и зависит от поддержки SADP конкретной моделью/прошивкой.
- Некоторые поля в SADP-ответах отличаются между моделями, поэтому часть информации может отображаться пустой.
- HCNetSDK (Device Network SDK) не включён в репозиторий: установите его отдельно из официального пакета Hikvision и при необходимости укажите путь к библиотеке через `HIKVISION_HCNETSDK_LIBRARY`. HCNetSDK не заменяет HCSADPSDK для прямых операций SADP в локальной сети. Hikvision отдельно предлагает [HCSADPSDK Linux64](https://open.hikvision.com/osp); по описанию SDK включает поиск, активацию, изменение сетевых параметров и сброс пароля. Для импорта ответа SADP XML и полного прямого управления SADP нужно добавить официальный Linux64 пакет и подключить его API. Репозиторий SadpToolsMac содержит описание функций, но не исходный код или переносимую Linux-библиотеку. Полный сброс пароля через импорт ответа SADP XML/security code пока не реализован.
- Настройка сетевых портов через ISAPI доступна только на моделях, которые отдают список `adminAccesses`; отвязка Hik-Connect доступна при `isSupportEZVIZUnbind=true` и поддерживаемом профиле шифрования.
- После смены IP текущее соединение прервётся; устройство нужно найти повторно.
